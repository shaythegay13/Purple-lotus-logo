# Serenity Pocket (retired)

Portfolio archive for [Shay Bouchles](https://github.com/shaythegay13). This repository keeps the Serenity Pocket logo and the static web prototype that displayed it.

Serenity Pocket is a retired brand and is no longer live. The brand evolved into PlayMind Labs, which uses a new logo. The GitHub repository is named `Purple-lotus-logo`.

## What the repository contains

A [Magic Patterns](https://magicpatterns.com) export of a Vite, React, and TypeScript interface. The previous README recorded the source design as [Dashboard Cards in Primary Colors](https://www.magicpatterns.com/c/tffn9vphc3pdd34ppk5c3x). The Magic Patterns commits use that same design name.

The app is client-side only. Copy, scores, posts, and prices are hardcoded in the page components. There is no backend, database, or authentication.

| Route | Screen |
| --- | --- |
| `/` | Dashboard. Welcome text, links to each section, a financial wellness score of 65/100, and two upcoming-session rows. |
| `/mental-health` | Mood tracker, financial wellness journal prompts, three CBT exercises, and two sample wellness goals. |
| `/etf-education` | An “AI Market Insight” paragraph, a featured-ETF table (VTI, IVV, QQQ, GLD, ESGV), and short ETF explainers. |
| `/financial-literacy` | Eight lesson cards. The page states that 2 of 8 are complete. |
| `/community` | Sample forum posts, a search field, and category controls. |
| `/challenges` | Sample challenges. Card images are loaded from `images.unsplash.com`. |
| `/crisis-support` | Static emergency-contact copy, grounding techniques, and links to outside sites. |

Shared pieces are `Layout`, `Sidebar`, `Header`, and `SectionCard`. `src/index.tsx` mounts `App`. `src/AppRouter.tsx` is not used by that entry file.

Tailwind theme colors in `tailwind.config.js`:

| Token | Hex |
| --- | --- |
| primary | `#4a6fa5` |
| secondary | `#4fb286` |
| tertiary | `#7e57c2` |
| background | `#d0d7e2` |

Icons come from `lucide-react`. The header title follows the route and falls back to “Serenity Pocket”. The header also shows the name “John Doe”.

## How the logo was built

The lotus is a committed image. This repository has no SVG, design file, or script that draws it. The PNG contains only `IHDR`, `IDAT`, and `IEND` chunks, so it does not name a design tool.

The interface around the logo was generated by Magic Patterns and committed as a Vite project (`package.json` name `magic-patterns-vite-template`). The stack declared there is React 18, React DOM, TypeScript, Vite 5, Tailwind CSS 3.4.17, PostCSS, Autoprefixer, React Router 6, and lucide-react 0.522.0. ESLint is set up for TypeScript and React hooks.

`src/index.css` and `tailwind.config.js` ask for the Inter typeface, then system fonts. `index.html` does not load an Inter stylesheet.

The UI tertiary purple (`#7e57c2`) is separate from the lotus color measured above.

## View and run

Open `public/logo.png` to see the mark on its own.

To run the prototype, use Node.js and npm. These commands were run with Node.js 22.14.0:

```bash
npm install
npm run dev
```

`npm run dev` starts Vite (`npx vite`). The logo is then available at `/logo.png`.

```bash
npm run build     # writes dist/
npm run preview   # serves that build
npm run lint
```

No lockfile is committed. `autoprefixer` and `postcss` are set to `"latest"`, so a later install can resolve different versions.

`npm run build` on this tree succeeded with Vite 5.4.21. `npm run lint` completed with no findings. `npx tsc --noEmit` reports unused `React` imports in `src/App.tsx`, `src/AppRouter.tsx`, and `src/index.tsx`. The build script does not run the TypeScript compiler.
